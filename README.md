# 주인님, 지금 상태 어때요?

컴퓨터의 CPU, 메모리, 저장 공간, 배터리 상태를 확인하고 현재 상태에 맞춰 하치와레 캐릭터가 반응하는 Python GUI 앱입니다.

## 의존성 설치

```bash
pip install -r requirements.txt
```

| 패키지 | 용도 |
|---|---|
| `psutil` | CPU / 메모리 / 디스크 / 배터리 수집 |
| `keyboard` | 전역 단축키 (창 토글 / 종료) |
| `winotify` | Windows 토스트 알림 |
| `Pillow` | 캐릭터 이미지 로딩 |
| `pyinstaller` | exe 빌드 시 필요 |

## 실행

```bash
python main.py
```

## exe 빌드

```bash
pyinstaller build.spec
```

빌드 완료 후 `dist/주인님_확인해주세요.exe` 생성됨.

> **주의**: 전역 단축키(Ctrl+Alt+M / Ctrl+Alt+Q)는 관리자 권한으로 실행해야 작동합니다.

## 주요 기능

- CPU / 메모리 / 디스크 / 배터리 상태 표시
- 상태에 따라 하치와레 캐릭터 무드 변경 (쾌적 ~ 살려줘요 5단계)
- 임계값 초과 시 Windows 토스트 알림
- 전역 단축키로 창 숨기기 / 다시 보이기 (기본 Ctrl+Alt+M)
- 전역 단축키로 프로그램 종료 (기본 Ctrl+Alt+Q)
- X버튼은 종료 대신 백그라운드로 숨김, 메인 화면 종료 버튼으로 완전 종료
- 설정창에서 표시 항목 / 임계값 / 단축키 / 알림 여부 조절

## 상태 기준 (터진 항목 수 기준)

| 단계 | 기준 초과 항목 수 | 멘트 |
|---|---|---|
| 0 | 없음 | 쾌적한 상태 |
| 1 | 1개 | 버틸만해요 |
| 2 | 2개 | 지쳤어요 |
| 3 | 3개 | 힘들어요 |
| 4 | 4개 | 살려줘요 |
